# Architecture Decision Records (ADR)

Use this folder to capture durable, high-impact technical decisions.

## Template

- **Title**
- **Status**: proposed | accepted | superseded
- **Date**
- **Context**
- **Decision**
- **Consequences**
- **Alternatives considered**

## Naming

`NNNN-short-kebab-case-title.md` (e.g. `0001-use-prisma-with-postgres.md`).
